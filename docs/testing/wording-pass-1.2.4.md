Every message the Part 3 checklist names, taken from the code of RC2 (`afd863f`; message code unchanged since).
Read each once and mark it: **OK**, **change now** (give the words; it means RC3 and a look at that message), or
**1.2.5**. Rule 4 asks each message to say what happened, whether the work is safe, and what to do next.

**NEW** or **CHANGED** = different from 1.2.3 (diffed against `cf4d4cb`). Everything else shipped in 1.2.3 and was
approved then; it is here so the set can be read together. `{…}` is filled in at run time. My notes are in *italics*.
